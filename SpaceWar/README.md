# 空间大战 · SGH-X458 源码版

双击项目根目录 `run.bat`，在启动器中选择「空间大战」。游戏默认显示简体中文，内部画面为 128×160 RGB565。窗口默认 400×500，支持启动器的四档尺寸、音量和静音。

## 自定义开局

- **进入场景与起始关卡**。可以保留标题菜单，也可以直接进入第 1–10 关。保留菜单时，按开始并确认开场后进入所选关卡。
- **初始后备机**。可选 0–100，默认 3，上限由 `layout.py` 的 `MAX_LIVES` 定义。选 0 时仍有一架当前飞船可用。
- **初始道具**。可选择飞船加速、敌人减速或奖命。加速和减速沿用固件的 40 次更新时长，奖命在第一拍增加一架后备机。初始道具在每次新游戏时生效。
- **无敌**。勾选后碰撞不再扣除后备机，也不进入续关提示，效果与《X-战机》的无敌一致。
- **游戏倍速**。支持 0.5×、0.75×、1×、1.5×、2×。倍速影响游戏更新，音频按原速播放。

勾选无敌、直接进入关卡，或修改起始关卡、后备机、道具和倍速时，成绩保存到 `.local/SpaceWar/practice-scores.bin`。进入下一关时沿用当前剩余后备机，续关按原版规则补充 3 架。

## 操作

| 场景 | 操作 |
|---|---|
| 菜单 | Enter 或 1 开始，2 查看最高分，3 查看帮助，4 继续 |
| 开场、过关和下一关提示 | Enter、空格或 5 确认 |
| 游戏中 | 方向键、WASD 或 2／4／6／8。点按一次后持续移动 |
| 停止移动 | 5 或空格 |
| 暂停与恢复 | Esc 暂停，Enter 或 4 恢复 |
| 续关提示 | 7 续关，9 结束 |
| 录入成绩 | 直接输入字母、数字或空格，←／→／↑／↓ 移动光标，Backspace 删除，Enter 保存 |
| 帮助或最高分 | Esc 或 Enter 返回菜单 |

成绩录入不再使用手机的九宫格多击选字。桌面版把键盘字符直接写入共用的名字缓冲，再由原版绘制例程刷新画面；字母统一为大写，最多 10 个字符。

排行榜写入项目根目录的 `.local/SpaceWar/scores.bin`，每条存档使用固件的 76 字节布局。运行时读取 `assets/runtime-data.bin` 和 WAV。刷机镜像与 Unicorn 用于离线提取和对照。

## 固件来源

游戏来自 `X458ZCEK1.s3` 的 G94 SpaceWar，回调入口为 `0x2379DC`。静态翻译文件 `game_flow.py` 包含围线、揭图、敌人更新、撞线、十关、续关及排行榜流程，并保留固件地址与底层状态布局。

`spacewar.py` 接入共用运行层并提供专属玩法适配。闭合区域需要扫描 2-bit 屏幕网格，小区域约需 48 万个翻译块。为覆盖无敌时的大面积填充，游戏把单次事件上限从默认的 50 万块提高到 1000 万块。

- 图像区间为 `0x5ADDD8–0x6123E5`，有 105 条索引色位图。运行时按固件绘图调用选择 RGB565 调色板。
- SMAF 音频区间为 `0x6123E5–0x61A8E3`，有 9 个容器。`assets/manifest.json` 记录各资源的地址、长度，以及原始 SMAF 的哈希。WAV 由 Yamaha MA-3 重新渲染为 48 kHz、16 位立体声。
- 主计时器请求 200 ms，换算为 44 个手机系统刻度。桌面按固件的刻度长度推进逻辑。
- 简体中文探针记录的菜单、帮助和开场图像地址分别是 `0x5E1AB1`、`0x5FBBD0` 和 `0x5E4618`。开场 SMAF 位于 `0x614C63`，长 4093 字节，调用返回地址为 `0x237A8C`。

## 验证与重新提取

```powershell
.\.venv\Scripts\python.exe -B -m tools.spacewar.verify
.\.venv\Scripts\python.exe -B -m tools.spacewar.extract
```

对照脚本覆盖三种语言的菜单、帮助、最高分、开场，第一关的移动、围线、结算、暂停、碰撞、续关和正常通关，以及排行榜录入与重读；另单独验证无敌开关、0–100 的初始后备机边界、成绩录入光标和区域填充的步数预算。后九关测试验证实战画面，并设置已过关状态来覆盖过场与任务完成。RGB565 帧、定时器、音频请求及存档字节与离线 ARM 对照器比较。真机屏幕颜色、扬声器表现和十关自然通关仍待实测。

若需重新渲染音频，使用 32 位 Windows Python 运行 `python -m tools.x_fighter.render_audio <ma3smwemu.dll> --assets SpaceWar/assets`。
